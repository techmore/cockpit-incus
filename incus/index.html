How these numbers are counted

Host collection continues with Cockpit closed. External includes public client addresses and explicitly configured public gateway ingress; gateway, direct public, local and unknown counts are shown separately. HTTP totals are completed requests and body bytes, including streams when they finish. NIC totals include internal traffic. HTTP windows use minute buckets; averages use available resource samples.

How this module accesses Incus

This page runs inside Cockpit and calls the incus command through Cockpit’s process bridge. Commands run as the signed-in host account. The account needs permission to access Incus; use your normal administrator workflow to grant it. The module does not send host credentials to an external service.
