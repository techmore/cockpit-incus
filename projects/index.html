How these numbers are counted

Visits are anonymous browser-tab sessions with a 30-minute inactivity limit, estimated per project; they are not a count of individual people. Active visits means a pageview in the last five minutes. New collection has no historical backfill. Tracking respects Do Not Track and Global Privacy Control and excludes admin/sign-in pages.

HTTP traffic counts completed requests and body bytes. Downloads are server → visitor; uploads are visitor → server. Streaming totals appear when a request completes. Instance network totals also include internal traffic. RAM includes filesystem cache. Disk percentage compares root-file usage to configured capacity and is an estimate.
